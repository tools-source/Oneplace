          Help & onboarding

          Need a refresher? Here’s the fastest way to get comfortable.

          1. Add a gain or owe in Finance, then filter by urgency.
          2. Use Organizer to set tasks with priority, due dates, and subtasks.
          3. Build Communication cards with transcripts and recordings.
          4. Export or import data in the Finance tab.

          Privacy & security

          Your data is stored locally on this device unless you export or share it.

          • Use HTTPS when hosting One Place to encrypt traffic.
          • Export backups regularly to avoid data loss.
          • Audio and images never auto-play.
          • Use strong device security if storing finances.
          Tip: Consider connecting to cloud storage or sign-in for multi-device backups.
